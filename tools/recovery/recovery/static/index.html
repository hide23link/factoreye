FactorEye 復旧ツール

今の DB を確認しています…
1

バックアップを選ぶ

戻したい時点のバックアップをクリックします。選ぶと、壊れていないかを確かめてから準備します（本番の DB には触りません）。

2

戻すものを選ぶ

バックアップと今の DB を比べた結果です。戻したいものにチェックを入れます（今の DB で消えているもの・測定値が足りないものは、最初から選ばれています）。

先に手順 1 でバックアップを選んでください。

3

内容を確認する

選んだ内容で書き戻すと、今の DB に何が追加されるかを、実際には書き込まずに確かめた結果です。

手順 2 で戻すものを選ぶと、ここに表示されます。

4

書き戻す

今の DB に無いデータだけを追加します。今あるデータは変更・削除しません。実行の直前に、今の DB の控えを自動で取ります。
