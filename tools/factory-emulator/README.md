# テスト工場エミュレータ

センサーや実機が無くても、FactorEyeのダッシュボード・アラーム機能をそれらしいデータで
試せるようにするための開発・デモ用ツールです。機械1台分の「生産数・温度・電力」を
5秒ごとにシミュレートしてbackendへ送信します。本体や`clients/`配下の公式クライアントとは
別物（これはテスト用の偽の機械）で、backendとは別プロセスとして動かします。

## 使い方

```bash
# backendが起動していること（リポジトリ直下で）
docker compose up -d

# 別ターミナルで
cd tools/factory-emulator
python3 emulator.py
```

初回起動時にセンサー（生産数・温度・電力）を自動登録します（既に登録済みならスキップ）。
以降はFactorEyeのダッシュボードにグラフウィジェットを追加すれば、変動するデータが
リアルタイムで表示されます。終了は Ctrl+C。

依存ライブラリはありません（`clients/raspberry-pi/factoreye_client.py` を再利用、標準
ライブラリのみ）。

## シミュレーションの挙動

- **生産数**（個/分相当、0〜100の指標）: 通常運転中はゆるやかにランダムウォーク
- **温度・電力**: 生産数に連動（高負荷ほど高温・高消費電力）。実機の熱慣性に近づけるため、
  値は指数平滑でゆっくり目標値へ近づく（カクカク飛ばない）
- **一時停止**: 一定確率で発生し、生産数は即座に0、電力は待機電力、温度は徐々に室温へ。
  15〜90秒程度でランダムに終わり、通常運転へ復帰する

## アラーム機能を試したい場合

自動登録されるセンサーには閾値（上限・下限）を設定していません。FactorEyeの
「設定」→「センサー」から、例えば温度センサーに上限40°C程度を設定すると、高負荷が
続いたタイミングでアラームが発生する様子を確認できます。

## 設定変更

`emulator.py` 冒頭の定数を直接書き換えてください（`FACTOREYE_HOST` / `INGEST_API_KEY` /
`SEND_INTERVAL_SECONDS` / 一時停止の発生確率・長さ等）。
