# AWS の控え（DR）の参考コード

記事「[自宅が止まっても戻せるように、AWS に控えを置く ― FactorEye 開発記(4)](https://qiita.com/)」で書いた仕組みの、一部を取り出した参考コードです。

**そのままは動きません。** 自分の AWS・Cloudflare の環境に合わせて作ったものから、仕組みが分かる部分だけを、設定値を外して載せています。完全版は非公開です。

| ファイル | 内容 |
|---|---|
| `standby-launch.sh` | 控えを、空きのある所に起動する。東京のスポット（AZ ごと）→ 大阪 → ムンバイの順に試し、空きが無ければ次へ進む |
| `spot-notice.sh` | スポットの回収の予告（約 2 分前）を見張り、来たら R2 に印を書く |
| `switch-guard.js` | DNS を付け替える前の安全装置。行き先が生きていないとき、控えが 2 台以上動いているときは断る |

## 使う側で用意するもの

- `standby-launch.sh` の設定ファイル（既定 `~/.factoreye-dr-standby.conf`）: 1 行 1 候補で `リージョン AZ AMI サブネット セキュリティグループ インスタンスプロファイル`
- 起動時に走らせる `standby-userdata.sh`（R2 から起動の一式を取って、DB を戻す。非公開）
- `spot-notice.sh` が読む `/etc/factoreye-dr.env`（R2 の接続情報）

DB の控え（WAL を R2 へ送る部分）と、控えから本番へ書き戻す復旧ツールは、このリポジトリの `infra/walg/` と `tools/recovery/` にあります。
